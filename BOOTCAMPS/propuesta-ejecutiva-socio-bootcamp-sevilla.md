# Propuesta ejecutiva para socio: bootcamps tech en Sevilla

## Oportunidad

Existe espacio para una oferta de formación tech más práctica y más conectada al trabajo real.

El mercado está saturado de formación genérica y de bootcamps de 10-12 semanas que sacan perfiles poco diferenciados. Sigue habiendo demanda de gente que sepa trabajar con herramientas actuales, construir producto, usar IA de forma práctica y rendir en procesos de selección técnicos.

La oportunidad no está en vender "otro curso de programación", sino en lanzar un programa largo, muy aplicado y orientado a empleabilidad real: `9 meses mínimo` y hasta `2 años`, cursable por módulos o de forma comprimida.

## Por qué esta propuesta es distinta

Este proyecto no nace solo desde la docencia. Nace desde una empresa que ya desarrolla software y apps.

Eso nos permite ofrecer algo que pocas academias pueden sostener con credibilidad:

- práctica sobre dinámicas y proyectos cercanos a entorno real,
- trabajo con repositorios, tickets, revisión de código y despliegues,
- visión completa de producto, no solo ejercicios académicos,
- preparación específica para entrevistas técnicas, tests y live coding.

A eso se suma el segundo diferencial, que es el formato: donde la competencia vende 12 semanas, aquí se ofrece un recorrido de 9 a 24 meses. No competimos con el bootcamp exprés, competimos con el primer año de experiencia real. Es lo que permite prometer oficio y no solo temario.

Actualmente contamos con una base real para ello:

- `5` softwares en construcción,
- `1` software ya publicado.

## Propuesta formativa inicial

### Bootcamp principal

`Full Stack + AI Product Development`

Áreas principales:

- React
- JavaScript / TypeScript
- Tailwind CSS
- Expo para mobile
- Python y FastAPI
- PostgreSQL
- GitHub, Agile/Jira y CI/CD
- Docker, Terraform, AWS, OVHcloud y Dokploy
- testing con Pytest y herramientas modernas de frontend
- IA aplicada al desarrollo: LLMs, LangChain y RAG
- entornos de trabajo como Cursor, Visual Studio Code y Codex
- preparación para entrevistas técnicas y live coding

### Formato y duración

- `9 meses` mínimo, hasta `2 años` en el recorrido completo.
- Dos vías: **por módulos**, con entrada y ritmo flexibles, o **comprimido**, más intensivo en horas semanales.
- Cada módulo tiene valor y cierre propios, de modo que el alumno pueda entrar por una pieza concreta y quedarse el programa entero.

### Programas cortos complementarios

También pueden lanzarse cursos más cortos para captar demanda y validar mercado:

- React
- Expo
- FastAPI
- Git/GitHub
- testing práctico
- IA para desarrolladores
- AI coding agents
- cloud deployment

## Modelo de arranque

La mejor forma de empezar es presencialmente en Sevilla, aprovechando la academia física del socio.

El piloto no arranca con el programa completo de golpe, sino con los primeros módulos, que ya se venden solos y permiten validar antes de comprometer dos años de calendario.

Ventajas:

- menor coste de arranque,
- mayor control de calidad,
- validación rápida del formato,
- alumno recurrente durante varios cursos, no matrícula de un trimestre,
- posibilidad de generar primeras promociones, testimonios y casos de éxito,
- base clara para escalar después a formato híbrido y online.

## Perfil de alumno

Los segmentos más lógicos para la fase inicial son:

- personas en reskilling,
- juniors con base técnica pero poca experiencia práctica,
- perfiles que quieran reconvertirse hacia desarrollo,
- empresas que necesiten formación aplicada en IA, cloud o desarrollo moderno.

## Posicionamiento

La propuesta debe venderse así:

> formación intensiva, práctica y actual, con aprendizaje sobre dinámicas reales de desarrollo y preparación para superar procesos técnicos de selección.

No se trata solo de enseñar tecnología. Se trata de acelerar la transición hacia un perfil profesional útil.

## Pricing orientativo

Dado que el programa dura entre 9 y 24 meses, el cobro natural no es una matrícula única sino:

- **precio por módulo**, que permite entrada de bajo compromiso,
- **cuota mensual** durante el recorrido,
- **descuento por compromiso de programa completo**, para asegurar permanencia.

Esto encaja mejor con la capacidad de pago del alumno y da previsibilidad de ingresos al centro.

Como referencia de partida (pendiente de recalcular para el formato largo):

- cursos cortos: `300€ - 900€`
- bootcamp part-time: `1.800€ - 3.500€`
- bootcamp premium más intensivo: `4.500€ - 6.500€`

Conviene tener presente que los precios de mercado que se suelen citar —Ironhack en torno a `6.250€`, 4Geeks en `5k-7k €`— corresponden a programas de semanas, no de meses. La comparación directa no aplica.

Para un primer lanzamiento en Sevilla, el argumento comercial no debería ser "más barato", sino más tiempo de formación por euro, reforzado con la práctica sobre proyectos reales.

## Subvenciones y financiación

Aquí conviene ser rigurosos.

Sí hay base real para explorar:

- programas EOI financiados con fondos europeos,
- convocatorias de formación subvencionada en Andalucía,
- formación bonificada para empresas vía FUNDAE.

Lo que no conviene afirmar todavía sin verificación exacta es un esquema cerrado del tipo:

> alumno paga 2.000€ y Europa aporta otros 6.000€

La oportunidad existe, pero debe tratarse como línea de desarrollo comercial e institucional, no como supuesto cerrado desde el inicio.
